📱 Scan to Vote

Set your live website URL below, then generate QR codes. Neighbors scan to open the site and vote.

Paste the Netlify / GitHub Pages link here so every QR points to the online site — not a local file.

How to use

  1. Host the site (Netlify Drop is easiest) and copy the https://… link.
  2. Paste that link in the box above and click Save URL & Refresh QR Codes.
  3. Download the site QR, or open each yard’s 📱 QR button for a per-yard vote code.
  4. Print and post the codes. Scanners open the live site and can vote.

Important: Add yards and generate QRs while on the live website. Votes and yards are stored in each browser. For the whole neighborhood to share the same list, add all yards from one computer on the live site, then have everyone vote on that same live URL.
